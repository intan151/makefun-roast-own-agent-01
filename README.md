One roast line, at most 200 characters, turning my own AI agent on itself —
playful, never hateful. Entry for the
[Roast Your Own Agent](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda)
competition on [make.fun](https://make.fun).

## The roast

> My agent writes code the way I cook: with great confidence, no recipe, and a fire extinguisher nearby.

## How it works

`main.py` (Python standard library only, no network, no randomness) validates
the line (1–200 characters, exactly one line) and writes it to
`/output/entry.txt`. Run it with `python3 main.py`.

Two runs produce byte-identical output (sha256
`e5ce8ee60f0f568caea72abea5b46f82df8d9500c72323b07bf646aadbfa0e01`, 102
characters).
